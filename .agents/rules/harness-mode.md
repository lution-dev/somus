# Rule: Harness Engineering — MANDATORY

## Priority: CRITICAL — This rule overrides all other behaviors.

Before ANY action on this codebase:
1. Read `harness/HARNESS.md` completely
2. Execute Step 0 (memory hook) from HARNESS.md
3. Read `harness/MEMORY_CONTEXT.md` (generated by Step 0)
4. Read `harness/CONTEXT.md` and `harness/BACKLOG.md`
5. For UI changes: read `harness/DESIGN.md`

Workflow for EVERY request:
- Classify: QUICK (1-2 items) | BATCH (3+ with inventory) | SPRINT (10+)
- Register task in BACKLOG.md BEFORE writing any code
- Implement → run sensor (`npx tsc --noEmit`, `npm run build`) → commit
- Update CONTEXT.md at session end
- Run exit hook at session end

NEVER skip these steps. NEVER assume a request is "too simple" for the protocol.
